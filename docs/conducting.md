# 指揮ロジックまとめ

しきくま/メトロノームモードの「どう振るか」を1枚に集約。コードは `web/index.html` と `spike/read_beat_groups.py`。

## 1. 1小節を何拍で振るか(N)

本質は **「1小節をいくつの"感じる拍(felt beat)"にまとめるか」**。これは拍子の種類とテンポで決まる。
= spec の `beat_groups`(拍のまとまり)そのもの。分母(2/4/8)は拍の"単位音符"を決めるだけで、本質ではない。

### 拍子の種類で分ける(割り切れるか)
- **単純拍子**(分子 2・3・4): 分子ぶん振る。各拍=分母の音符。
  - 2/2→2拍(各2分音符)、3/2→3拍、3/4→3拍、4/4→4拍。
- **複合拍子**(分子が3で割り切れる: 6・9・12、主に /8): `分子/3` 拍。各拍=付点音符(=3つ分)。
  - 6/8→2拍、9/8→3拍、12/8→4拍。
- **混合(不等)拍子**(5・7 等、2・3で割り切れない): **2+3 / 2+2+3 のグループで振る**。拍の長さが不均等。
  - 5/8→2拍(2+3)、7/8→3拍(2+2+3)、5/4→(2拍 2+3 が普通)。

### テンポでも変わる(重要)
- **速い**ほど拍をまとめる: 速い3/4→**1拍(1 in a bar)**、速い4/4→2拍(half-time)、速い6/8→2拍。
- **遅い**ほど割る: 遅い6/8→6拍、遅い4/4→8分で割って振ることも。
- → 「割り切れ方」+「テンポ」で felt beat の数が変わる。= 音楽的判断(§6のAI任せ候補)。

### 現状の実装(`measurePulses`)と、理想とのギャップ
`measurePulses(info)` が拍子+beat_groups から**拍の配列**(各値=4分音符いくつ分=その拍の長さ)を返す。N=長さ。
各拍 = 分母ぶん: `4/den`(/2→2, /4→1, /8→0.5)。**分母は何でも対応済み**(2/2・3/2 もOK)。

| ケース | 現状の挙動 | 理想 |
|---|---|---|
| 8分系 + 分け方あり | グループ数で振る(5/8[2,3]→2, 7/8[2,2,3]→3)✓ | ✓ |
| 複合 6/8 連桁[3,3] | 2拍 ✓ | ✓ |
| 単純 4/4, 3/4, 2/2, 3/2 | 分子ぶん ✓ | ✓(ただし速い曲のまとめは未対応) |
| **5/4, 7/4** | **2+3 等にまとめる** ✓(2026-10-12 対応) | ✓ |
| テンポによるまとめ/割り | **未対応**(テンポ見てない) | 速い=まとめ, 遅い=割り |

- 分け方(beat_groups)は `read_beat_groups.py`(**振り方決定**)が **分子5以上の小節**を対象に、
  楽譜の連桁を最優先＋無ければ指揮慣習(5→2+3, 6→3+3, 7→2+2+3…)で決める。**合計≠分子なら慣習で補正**。
- まだ **テンポは未考慮**(速い3/4を1で振る等は未対応)。§6 のAI判断で将来対応。

## 2. 指揮図形(打点パターン)

`conductorFig(N)`(web/index.html)が図形を返す。座標は単位系(x: -1左〜+1右, y: -1上〜+1下)。
- `b` = 打点(拍が落ちる下の点, y=1)。**1拍目は必ず中央下** `[0,1]`(ダウンビート)。
- `a` = 拍間の跳ね上げ頂点(apex, 高い)。**a の最後 = 始点**(中央上 `[0,-0.9]`、全拍子共通で固定)。
- 手(星)は 打点j →(上へ)apex j →(下へ)次の打点、を繰り返す。

現在の仮データ(※ 手描き図形で差し替え予定):
```
1: b=[[0,1]]                                  a=[[0,-0.5]]
2: b=[[0,1],[0,1]]                            a=[[0.8,-0.55],[0,-0.9]]
3: b=[[0,1],[0.6,1],[-0.6,1]]                 a=[[0.5,-0.6],[0,-0.6],[0,-0.9]]
4: b=[[0,1],[-0.65,1],[0,1],[0.65,1]]         a=[[-0.5,-0.6],[0.1,-0.68],[0.5,-0.6],[0,-0.9]]
5: b=[[0,1],[-0.6,1],[0,1],[0.5,1],[0.85,1]]  a=[[-0.45,-0.55],[-0.1,-0.65],[0.3,-0.55],[0.7,-0.55],[0,-0.9]]
6: b=[[0,1],[-0.5,1],[-0.85,1],[0,1],[0.5,1],[0.85,1]]  a=[...,[0,-0.9]]
7以上: 正N角形で代用(暫定)
```

## 3. タイミング(不均等)

- 各拍の長さ = `measurePulses` の値 × (60/テンポ) 秒。
- 5/8 [2,3] なら 2拍目(1.5)が1拍目(1)より**1.5倍長い** = 不均等に振る。
- 打点は拍の頭(frac 0)に到達する。

## 4. 動きの質

- **直線⇄曲線をテンポでブレンド**(`curveK = clamp((160-tempo)/110, 0,1)`)。
  - 遅い曲(♩60→curveK 0.91)= 曲線的(2次ベジェ、apexを通る弧)。
  - 速い曲(♩136→0.22, ♩160+→0)= 直線的(角ばる)。実際の指揮の物理に合わせた。
- **始点から始まる**: 前拍(準備)で 始点→1拍目 を振る(`prePhase`)。
- **連続**: 軌跡はコメットの尾(約0.8秒)。小節/拍子が変わっても繋がる(瞬間移動しない)。始点は全拍子で中央上に固定。

## 6. 役割分担: 「仕様」はルール、「表現」はAI(agent)

指揮は「打点(どこで拍が落ちる)+大まかな軌道」までが共通ルールで、**どう振る(速さ・ため・弧の深さ・強弱の乗せ方)は指揮者次第**。
なので設計もそう分ける:

- **ルール(決め打ち / データ)**: 打点パターン(`conductorFig`)、felt beat の基本(単純/複合/混合)。
- **AI(agent)に判断させたい**:
  - **felt beat のまとめ方**: 拍子 + **テンポ** + ジャンル/曲想から「何拍で振るか(N)と分け方」を決める(5/4を2+3にする/しない、速い3/4を1で振る 等)。
  - **表現(軌道の具体化)**: 打点+大まかな軌道を入力に、カーブの深さ・ため・加減速・強弱での動きの大小を決める。
  - 今は近似で実装(テンポで直線⇄曲線ブレンド §4)。将来はここをAIに。
