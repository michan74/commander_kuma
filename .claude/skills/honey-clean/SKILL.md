コード内の 🍯 付きコメントを削除する。

🍯 はユーザーへの説明として一時的に書いたコメントの目印であり、コードベースに残さない。
コメント規約は `CLAUDE.md` の「コードコメント」を参照。

# 手順

## 1. 対象ファイルの特定

**target-path** が指定されていればその配下を対象にする。
省略された場合は、変更差分のあるファイルを対象にする:

```bash
git diff --name-only HEAD; git diff --cached --name-only; git ls-files --others --exclude-standard
```

## 2. 🍯 コメントの検索

対象ファイルから 🍯 を含む行を探す。`node_modules` / `.output` / `dist` / ロックファイルは除外する。

```bash
grep -rn "🍯" <対象> --exclude-dir=node_modules --exclude-dir=.output --exclude-dir=dist
```

## 3. 削除

以下の形で削除する。**コメント記号は言語に合わせて判断する**（`//` `#` `<!-- -->` `/* */` など）。

- **行全体が 🍯 コメントの行** → 行ごと削除する
  - 直前・直後に空行が並んで2行以上連続する場合は1行に詰める
- **コード行末尾の 🍯 コメント** → コメント部分のみ削除し、行末の余分な空白も除去する
- **複数行コメントブロック内に 🍯 がある場合** → 🍯 の行のみ削除する。
  ブロック内が実質空になったらブロックごと削除する

**🍯 が付いていないコメントには一切手を付けない。**

## 4. 検証

- 削除後に 🍯 が残っていないことを確認する
- そのプロジェクトの lint / 構文チェックを実行して壊れていないことを確認する

# ルール

- **削除したコメントの内容は報告しない**（黙って消す）
- 削除したファイル数・箇所数だけ簡潔に伝える
- 🍯 コメントが1件も無ければ「なし」と伝えて終了する
- コメント以外のコード（文字列リテラル内の 🍯 など）は削除しない。判断に迷う箇所があれば消さずにユーザーに確認する
