# 2026-10-05 作業メモ

## やったこと

### 段階2の issue(小節線の見落とし=分割)を実装した

昨日の宿題「AIに任せる部分(見落とし→分割)の設計・実装」。核心は「AIは座標を出さない方針なのに、どこで割るか」。

**方針: 段階1が捨てた縦線候補をAIに番号で選ばせる**
* 見落としの真因は符尾判定の誤爆(10/04 調査)=段階1は小節線を縦線候補としては見つけているが `stem=1` で捨てている。
* その「全高・濃いのに捨てた線」を**分割候補(D番号)**として残し、画像にマゼンタで描く。
* AIは見落とし位置のD番号を選び `splits: {枠番号, at:[D番号]}` で返す。座標は段階1の検出値を使い、**AIは選ぶだけ**。「座標を出させない」原則を守りつつ「AIが分割位置も提案」を実現。

### 実装

* `barlines.py`: cand に `missed`(spans かつ stem かつ darkness≥180)フラグを追加
* `detect_measures.py`: `missed` の線にD番号を振り、`split_candidates.json` に保存。段画像にマゼンタ線+D番号を描画。可視化用に `staves.json` へ straighten の `matrix` も保存
* `ai_correct.py`: `Split` モデル(枠番号+D番号)を追加。プロンプトでD線の意味と分割指示を説明。`apply_corrections` に分割を統合(`split_bbox`)。補正後の枠を matrix 逆変換で元写真に重ねる `corrected_overview.jpg` を出力
* `run.sh`: ai_correct に元写真パスを渡す
